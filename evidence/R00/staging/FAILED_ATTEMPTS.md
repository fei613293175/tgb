# R00 失败尝试与恢复记录

这些尝试均在隔离路径中处理，没有修改生产站点代码。

## 1. 面板数据库凭据读取方式错误

- 失败舞台：`/www/staging/tg-h5-ui-r00.failed-root-auth-20260726T124600+0800`
- 失败备份：`/www/backup/tg-h5-ui-r00/20260726T124600+0800.failed-root-auth`
- 原因：面板 SQLite 中存储的数据库密码字段不能直接当作 MySQL root 明文密码使用。
- 修正：使用宝塔面板自身的加密解密能力读取运行时凭据；凭据不输出、不落入文档。

## 2. GTID 导入失败

- 失败舞台：`/www/staging/tg-h5-ui-r00.failed-gtid-20260726T124744+0800`
- 失败备份：`/www/backup/tg-h5-ui-r00/20260726T124744+0800.failed-gtid`
- 原因：逻辑转储携带 GTID 状态，隔离数据库导入受到限制。
- 修正：转储使用 `--set-gtid-purged=OFF`；失败舞台用户/数据库已清理后重新建立。

## 3. 面板 Python 版本兼容

- 原因：面板 Python 3.7 不支持 `Path.write_text(..., newline=...)`。
- 修正：使用兼容的显式文件打开方式写配置，同时保持 LF。

## 4. 监听端口与目录权限

- `18080` 已被 Docker 占用，改用仅回环的 `18081`。
- `/www/staging` 祖先目录初始权限导致 Nginx 不能遍历，使用 `namei` 定位后将必要祖先调整为 `711`；私有证据目录保持 `700`。
- 舞台 `.user.ini` 的 `open_basedir` 已改为舞台根，避免生产路径耦合。

## 5. 最终结果

成功快照为 `20260726T125247+0800`。失败尝试保留为有明确后缀的隔离证据，不作为可继续开发的舞台环境。
