# R03 运行时与截图审计

## 覆盖

- 页面：11 个认证、协议、帮助和关于页面
- 视口：360x800、390x844、430x932
- 截图：33 张，文件名为 `PAGE-ID-R03-AFTER-viewport.png`
- 审计数据：3 份 `R03-BROWSER-viewport.json`

三档视口均满足：横向溢出为 0、公共 UI CDN 为 0、资源失败为 0、控制台错误为 0。
认证页可见文本输入最小高度 48px、字号 16px；可点击控件和复选框命中区最小 44px。
帮助页弹窗的打开和关闭状态均实际操作通过。

所有页面使用浅色背景。长协议正文保持正常横向阅读，不出现 390px 窄列逐字换行；帮助
和关于页的旧深色壳层、空白分隔框及固定头部高度已由局部样式覆盖。

注册页运行时会显示邀请编号。三档截图均在截图前对该节点执行临时 DOM 脱敏并显示
`[已脱敏]`；JSON 的 `redacted=true` 是保存截图的强制断言。证据不得反向恢复、输出或
传播真实编号。每张截图前还断言页面滚动位置为预期位置，避免截到错误区段或残留状态。
