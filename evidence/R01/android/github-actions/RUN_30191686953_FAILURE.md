## 原因

这次已经显式传入 `--channel=3`，仍返回同一“找不到包”错误，因此 Run 3 的
“仅缺预览通道”判断被证伪。对已成功构建正式 APK 的服务器隔离镜像做只读交叉
核验，得到 SDK Manager 的精确已安装包：

```text
platforms;android-37.0 | 2 | Android SDK Platform 37.0 | platforms/android-37.0
```

失败根因为把 Gradle 的整数 `compileSdk = 37` 机械转换成了并不存在的
SDK Manager 包名 `platforms;android-37`。API 37 的实际包名带 `.0`。

## 第四次修复

1. 工作流安装精确包 `platforms;android-37.0`；
2. 安装后断言 `${ANDROID_SDK_ROOT}/platforms/android-37.0/android.jar`；
3. 继续保持 `compileSdk 37 / targetSdk 36`；
4. 后续 run 必须继续通过构建、APK 门禁、Android 36 模拟器、截图和日志检查。
